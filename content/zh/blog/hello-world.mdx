欢迎来到我的博客！这是这里的第一篇文章，简单聊聊这个网站的来龙去脉。

## 为什么要写博客

写作是最好的思考方式。把学到的东西写下来，才知道自己是不是真的懂了；把踩过的坑记录下来，也希望能帮到后来的人。

> 输出是最好的输入。—— 无数前辈的共识

## 这个网站是怎么搭起来的

- **框架**：[Next.js](https://nextjs.org) 16 + React 19，App Router + Turbopack
- **语言**：TypeScript
- **样式**：Tailwind CSS 4，支持暗色模式
- **内容**：文章用 MDX 编写，支持 Markdown 语法和代码高亮
- **国际化**：next-intl，中英双语，中文为默认语言

写文章只需要在 `content/zh/blog` 或 `content/en/blog` 目录下放一个 `.mdx` 文件：

```ts
// 这就是全部——剩下的事情交给框架
export function greet(name: string) {
  return `你好，${name}！`;
}
```
