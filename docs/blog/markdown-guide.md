## 代码块

支持语法高亮（亮色/暗色双主题）：

```python
def fib(n: int) -> int:
    """斐波那契数列"""
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a
```

```bash
# 也支持命令行
npm run dev
```
